# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of Mach.

| Version | Supported |
| ------- | --------- |
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

Older versions are not guaranteed to receive security fixes.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Mach, please report it privately through one of the following channels:

- **Email:** security@machframework.dev
- **GitHub:** [Private Vulnerability Reporting](https://github.com/machframework/mach/security/advisories/new)

Please do not disclose security vulnerabilities through public GitHub issues, discussions, or pull requests before coordinated disclosure.

When reporting a vulnerability, please include:

- A description of the vulnerability and its potential impact
- The affected Mach version(s)
- Steps to reproduce the issue or a proof of concept, if available
- Any suggested mitigations or fixes

## Response and Disclosure

We aim to acknowledge security reports within 7 days.

Reports will be reviewed and investigated, and reporters will be informed whether the issue is confirmed, requires further investigation, or is not considered a security vulnerability.

Confirmed vulnerabilities will be prioritized based on their severity and impact. Resolution timelines may vary depending on the complexity of the issue.

We ask reporters to coordinate public disclosure with the maintainers, preferably after a fix or mitigation is available.

Thank you for helping keep Mach and its users secure.
